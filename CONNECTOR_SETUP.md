# AROS 1.5.1 Google Connector Setup

The LSU Outlook connector is no longer required. Outlook forwards selected messages to your existing Gmail account as attached `.eml` messages.

AROS needs one Google OAuth connection for:

1. reading the forwarded-message intake in Gmail, and
2. monitoring the Google Docs grant proposal.

## Google Cloud configuration

Create a Google Cloud project for AROS, enable:

- Gmail API
- Google Docs API
- Google Drive API

Configure an OAuth consent screen and create an OAuth 2.0 **Web application**.

Authorized redirect URI:

`https://vros-iota.vercel.app/api/google/callback`

Add the Google account you intend to connect as a test user if the OAuth app remains in Testing mode.

## Vercel environment variables

Add:

`NEXT_PUBLIC_APP_URL`
Value: `https://vros-iota.vercel.app`

`GOOGLE_CLIENT_ID`
Value: OAuth client ID from Google Cloud

`GOOGLE_CLIENT_SECRET`
Value: OAuth client secret from Google Cloud

`GOOGLE_TOKEN_ENCRYPTION_KEY`
Value: a long random secret generated by you

`SUPABASE_SERVICE_ROLE_KEY`
Value: the Supabase server-side service-role/secret key

Do not prefix the last three secret values with `NEXT_PUBLIC_`.

Redeploy after saving environment variables.

## Google permissions requested by AROS

- Gmail read-only
- Docs read-only
- Drive metadata read-only
- basic OpenID/email identity
- offline access for a refresh token

AROS 1.5.1 does not request Gmail send or compose permission.
